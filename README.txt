QUBIX PORTFOLIO WEBSITE

Included pages: index.html, about.html, skills.html, experience.html, education.html, contact.html
Shared stylesheet: Assets/css/style.css

SETUP:
1. Extract this ZIP file and open the QUBIX_Portfolio folder in VS Code.
2. Create Assets/image if it does not exist.
3. Copy your profile photo into Assets/image and name it ansu.jpeg.
4. Open index.html in your browser or use VS Code Live Server.
5. Replace YOUR_EMAIL@example.com in contact.html with your real email address.
6. Adjust the skill bars in skills.html to reflect your actual proficiency.

Project descriptions are kept general. Add specific technologies only if you used them.
